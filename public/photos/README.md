# Carpeta de Fotos

Pon aqui tus fotos (por ejemplo `primera-cita.jpg`, `viaje.webp`...).

Una vez copiadas, referencia cada foto desde los archivos de `/src/data/`
usando una ruta que empiece por `/photos/`. Ejemplo:

```js
// en /src/data/gallery.js
photo: '/photos/tu-sonrisa.webp',
```

> Consejo: usa imagenes de ~1000 px de ancho en formato `.webp` para que
> carguen rapido, sobre todo en movil.
